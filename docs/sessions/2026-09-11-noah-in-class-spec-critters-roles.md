## Learned (with sources)
- Claude Design shares usage limits with chat + Claude Code (since its Jun 17, 2026 overhaul) and hands designs to Claude Code. [VentureBeat](https://venturebeat.com/technology/anthropic-ships-major-claude-design-overhaul-with-design-system-imports-code-round-trips-and-a-fix-for-its-token-burning-problem)
- Couples apps are proven and crowded: Paired has 8M downloads and ~100K daily couples; Candle has 150K couples, ~50% DAU/MAU, and widgets. [Paired](https://www.paired.com/), [Candle](https://apps.apple.com/us/app/candle-couples-relationship/id6743355635)
- Florida HB 3 applies only to platforms meeting all 4 criteria (incl. algorithmic feed + addictive features); Texas SCOPE has a small-business exemption and is partly blocked. [Hunton](https://www.hunton.com/privacy-and-cybersecurity-law-blog/florida-enacts-legislation-restriction-social-media-accounts-for-minors), [Kelley Drye](https://www.kelleydrye.com/viewpoints/blogs/ad-law-access/the-scope-act-in-focus-what-you-should-know-about-texass-partially-blocked-youth-privacy-statute)
- Big platforms default teens to no stranger contact (Discord Mar 2026, Instagram). [Childhelp](https://childhelp.org/the-latest-apps-parents-should-know-about-a-2026-guide-to-kids-online-safety/)
- Avatar systems studied: Google Docs' 73 anonymous animals, Netflix's rotating sets, Notion Faces, Duolingo's 3-shape language, Among Us's colour + silhouette, Finch's hatch-and-name ownership. See `research/avatar-case-study.md`.
