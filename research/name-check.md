# Name Check: "Widget Rather" (ROADMAP 1.3)

_2026-09-11, Noah's session. Research, not a legal trademark search._

## Result: looks available ✅ (with one caveat)
| Check | Result |
|---|---|
| Web search, "Widget Rather" | No app or brand by that name found ([search results](https://prettyprogress.app/blog/best-free-widget-apps-for-iphone) were only generic widget articles) |
| Web search, "WidgetRather" | Nothing; only unrelated "Widget" topics (a 1990 TV show, a beer widget, etc.) |

Live Polls, This or That, For Kids, The Game…), **none named Widget Rather, and none mention widgets** ([Either](https://apps.apple.com/us/app/either-you-would-rather/id1437917909), [Live Polls](https://apps.apple.com/us/app/would-you-rather-live-polls/id1352732673), [This or That](https://apps.apple.com/us/app/would-you-rather-this-or-that/id6749407246)) |
| Domains | `widgetrather.com` and `widgetrather.app` **don't resolve**. They're probably unregistered, but that isn't proof (a registered domain without DNS also fails). Check a registrar to be sure |
| Length | "Widget Rather" = 13 characters, well under the 30-character limit ([AppScreenshotStudio](https://appscreenshotstudio.com/blog/app-store-metadata-for-indie-devs-title-subtitle-keywords-2026)) |

## The caveat
- **App Store names must be unique**, and the only definitive check is creating the app record in App Store Connect; a taken name gives the error "already been used" ([IPRightsHub](https://iprightshub.com/blog/how-to-check-if-app-name-is-already-taken-cross-store-guide-2026), [Apple Forums](https://developer.apple.com/forums/thread/45460)). That needs the Apple Developer account (ROADMAP 7.2).
- Apple settles name conflicts between developers by **trademark** ([PTKD](https://ptkd.com/journal/can-two-apps-have-the-same-name-app-store)). We haven't done a trademark search; a lawyer can at ROADMAP 8.5.
- Only the **store name** must be unique. The home-screen display name doesn't ([AxonBuild](https://axonbuild.com/blog/app-store-listing-name-and-description)).

## Recommendations
1. **Register the domain** once the team agrees (`widgetrather.app` or `.com`). We need one anyway for the privacy policy + support page (ROADMAP 3.2).
2. **Spelling:** use "**Widget Rather**" on the App Store (readable, searchable) and "**WidgetRather**" as the wordmark. Never "WigetRather" (the typo in mockup 01).
3. **Subtitle idea** (30 chars max): "Daily would you rather" (22) or "A little question, every day" (28), from the mockup tagline.
4. **Backup names** in case it's ever taken: "Rather: Daily Widget", "Would U Rather Widget", "Rathr".
