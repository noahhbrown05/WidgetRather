# Widget Rather

A home-screen widget that drops a "Would you rather?" question every morning. Answer it, see how your friend groups and communities answered, react, and talk about it at school.

A learning project. Greg = back end, Noah = front end + design, Tiago = advisor (D-017). **Current phase: Stage 1 of the roadmap. No app code yet** (D-014).

## Start here
1. **`docs/STATUS.md`**: one page on where we are. Read this first, every time.
2. **`docs/ROADMAP.md`**: the step-by-step from here to launch and beyond (no timeline).
3. **`docs/MVP-SPEC.md`**: exactly what the MVP does.
4. **`docs/DECISIONS.md`**: what's decided and what's proposed. Add your sign-off.
5. `design/`: mockups and the Pastel Critters avatar roster (`design/critters.md`).
6. `docs/COLLABORATION.md`: how we work together (setup, branches, PRs, accounts).
7. `CLAUDE.md`: the rules Claude follows here (Rule 1: no facts from memory; always research and cite).
8. `research/`: market, tech stack, safety & legal, testing, name check, avatar case study, Chris Raroque's playbook.
9. `docs/sessions/`: short summaries of each Claude session.
