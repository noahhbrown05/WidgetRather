# Widget Rather

A home-screen widget that drops a "Would you rather?" question for middle and high schoolers. Answer it, see how your friend group answered, react, and talk about it tomorrow.

A learning project by Noah, Tiago, and Greg. **Current phase: research & positioning. No app code yet** (see `docs/DECISIONS.md` D-001).

## Start here
1. **`docs/STATUS.md`**: one page on where we are. Read this first, every time.
2. **`docs/COLLABORATION.md`**: how the three of us work together (setup, branches, PRs, accounts).
3. **`docs/DECISIONS.md`**: what's decided and what's proposed. Add your sign-off.
4. `CLAUDE.md`: the rules Claude follows here (Rule 1: no facts from memory; always research and cite).
5. `research/`: market & positioning, tech stack, safety & legal, Chris Raroque's playbook.
6. `docs/sessions/`: short summaries of each Claude session.
